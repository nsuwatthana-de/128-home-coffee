# แอปร้านคาเฟ่ (สั่งผ่าน QR + หลังร้าน)

แอปเว็บแบบ static ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ HTML/CSS/JavaScript ล้วน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าลูกค้า เปิดจาก QR ที่โต๊ะ เช่น `index.html?table=A3` |
| `staff.html` | หลังร้าน: ออเดอร์, เมนู, การเงิน (รายรับ-รายจ่าย), รายงาน |
| `config.js` | ชื่อร้าน และค่าเชื่อมต่อ Supabase |
| `js/store.js` | ชั้นข้อมูล: Supabase ถ้าตั้งค่าไว้ ไม่งั้นใช้ localStorage |
| `supabase/schema.sql` | ตาราง, กฎความปลอดภัย (RLS), ฟังก์ชันสร้างออเดอร์ |

## ลองใช้งานทันที (โหมดทดลอง)

1. เปิด `cafe/` ด้วย static server เช่น `python3 -m http.server 8000` แล้วเข้า `http://localhost:8000/cafe/`
2. หน้าลูกค้า: `http://localhost:8000/cafe/index.html?table=A1`
3. หน้าหลังร้าน: `http://localhost:8000/cafe/staff.html`

โหมดนี้เก็บข้อมูลในเบราว์เซอร์นี้เท่านั้น เหมาะกับการดูหน้าจอและลองระบบ ไม่ใช่การใช้งานจริงหลายเครื่อง

## ตั้งค่าใช้งานจริง (Supabase)

1. สร้างโปรเจกต์ที่ supabase.com
2. ไปที่ **SQL Editor** แล้วรันไฟล์ `supabase/schema.sql` ทั้งไฟล์
3. ไปที่ **Authentication > Users** สร้างบัญชีพนักงาน (อีเมล + รหัสผ่าน) ตามจำนวนคนที่ต้องใช้
4. ไปที่ **Project Settings > API** คัดลอก `Project URL` และ `anon public` key ใส่ใน `config.js`:
   ```js
   supabaseUrl: 'https://xxxx.supabase.co',
   supabaseAnonKey: 'eyJ...',
   ```
5. ตั้งชื่อร้านในค่า `shopName` ใน `config.js`
6. นำโฟลเดอร์ `cafe/` ไปวางบนโฮสต์แบบ static (เช่น GitHub Pages, Netlify, Vercel) แล้วพิมพ์ QR ของแต่ละโต๊ะ ชี้ไปที่ `.../index.html?table=โต๊ะ`

## หลักความปลอดภัยที่ใช้

- ลูกค้าเรียกเฉพาะ `place_order` ซึ่งคำนวณราคาจากตาราง `menu_items` ในฐานข้อมูล หน้าเว็บแก้ราคาไม่ได้
- ลูกค้าอ่านได้เฉพาะเมนูและติดตามออเดอร์ด้วย id แบบ uuid ที่เดาไม่ได้
- การจัดการเมนู ออเดอร์ และรายจ่าย ต้องล็อกอินเป็นพนักงานก่อน
- ยังไม่มีการเรียกเก็บเงินจากลูกค้าผ่าน PromptPay อัตโนมัติ พนักงานกดรับเงินสดหรือโอนเองที่หลังร้าน

## สิ่งที่ยังไม่มีใน v1

- PromptPay QR และตรวจยอดโอนอัตโนมัติ
- จอครัวแยกสถานี (ตอนนี้ดูออเดอร์ทั้งหมดในหน้าเดียว)
- ตัดสต็อกวัตถุดิบ, เครื่องพิมพ์ใบเสร็จ, สมาชิก/แต้ม
- ออกใบเสร็จ/ส่งออก CSV
